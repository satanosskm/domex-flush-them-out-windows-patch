DOMEX: FLUSH THEM OUT — WINDOWS COMPATIBILITY PATCH

ENGLISH

The original game is required and is not included.

1. Extract this ZIP.
2. Place Domex-Windows10-Patch.exe next to flush_them_out.exe in the game folder.
3. Double-click the patcher. It creates the patched version and starts the game.

On first launch, Windows may display a security warning because the program is not digitally signed. Click More info, then Run anyway.

Your original game file is kept intact. No administrator rights are required.
For future sessions, launch flush_them_out-win10.exe or the patcher.
Read README.md for the full instructions.
