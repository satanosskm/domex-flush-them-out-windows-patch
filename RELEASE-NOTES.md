# Domex Windows Compatibility Patch v1.0.0

## English

An unofficial patch to play **Domex: Flush Them Out** on Windows 10. The original game is required and is not included.

### Installation

1. Download `Domex-Windows10-Patch.exe`, or extract the player ZIP.
2. Place the patcher next to the game's `flush_them_out.exe`.
3. Double-click it. The patched version is created and the game starts automatically.

The original file is kept intact. No administrator rights are required.

On first launch, Windows may display a security warning because the program is not digitally signed. Click **More info**, then **Run anyway**.

For future sessions, launch `flush_them_out-win10.exe` or the patcher.

## Français

Un patch non officiel pour jouer à **Domex: Flush Them Out** sous Windows 10. Le jeu original est nécessaire et n’est pas inclus.

### Installation

1. Télécharge `Domex-Windows10-Patch.exe`, ou extrais le ZIP destiné aux joueurs.
2. Place le patcher à côté du fichier `flush_them_out.exe` du jeu.
3. Double-clique dessus. La version corrigée est créée et le jeu démarre automatiquement.

Le fichier original est conservé intact. Aucun droit administrateur n’est nécessaire.

Au premier lancement, Windows peut afficher un avertissement de sécurité, car le programme n’est pas signé numériquement. Clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.

Pour rejouer, lance `flush_them_out-win10.exe` ou le patcher.
